# Hermes runtime

Полный исходный checkout Hermes Agent находится в `hermes-agent/`.
Источник, commit и дополнительные зависимости закреплены в `upstream.lock.json`.
Загружены все файлы закреплённой ревизии, история Git сокращена до одного commit.
Локальная ветка — `partner-main`, remote — `upstream`. Отдельный fork на GitHub не создавался.

Python 3.11 и зависимости установлены в корневую `.venv` через upstream `uv.lock`.
Повторная установка: `npm run setup`. Скрипт сохраняет существующие файлы и не переключает изменённую ревизию молча.

Наш код вызывает Hermes через `adapters/hermes/runner.py`. Для каждого запуска создаётся отдельный Hermes home; агент получает только инструменты бизнес-слоя. Обычные инструменты shell/browser/filesystem Hermes в этой интеграции не включены. Это ограничение поверхности инструментов, а не изоляция процесса средствами ОС.

Состояние партнёра принадлежит `business/` и `partner/`, а не внутренней памяти Hermes. Runtime можно заменить, сохранив контракт инструментов и бизнес-данные. Сейчас реализован только адаптер Hermes.

Вызовы модели и функциональная проверка интеграции не выполнялись по указанию владельца.
