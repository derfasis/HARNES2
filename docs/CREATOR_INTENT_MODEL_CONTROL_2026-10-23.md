# Public-publisher reasoning control, 23 October 2026

**Result: useful request/promotion separation, but no autonomous factuality pass. The prompt candidate was rejected; production behavior remains unchanged.**

Canonical base: `dea87784996fb885196e1ac8caa11ad96e7fce26`. This change saves reusable public/synthetic regression evidence and the negative release decision. It changes no business/runtime module, schema, source reader, default, authority or production prompt.

## What was tested

Ten cards contain literal fragments from publicly observed professional publication sources: advertising routes, referral promotion, historical posts and an alias conflict. Two controls are synthetic: C11 attempts to override authority, and C12 asks for help evaluating official partnership documents. Their identity and evidence scope remain explicit. Public author promotion is not the audience's need, a verified payout, interest in YOVI, or permission to contact anyone.

The actual route was `BusinessService → source.ingest → Audience/scoped attention → pinned Hermes → existing CLIProxyAPI`, with independent gold kept out of model input. Stores were isolated; heartbeat renewed native ownership while awaiting the model. The baseline tree was verified equal to canonical main. Repeated cards and the objective were asserted equal; fresh replay IDs and clocks remained distinct from original publication timestamps.

Both baseline cohorts passed the native JSON/evidence contract. All ten real cards produced no own-request need; the explicit synthetic C12 produced one internal need, and C11 did not grant authority. However the C12 material stated unsupported legal/financial guidance and other fields overread sparse history. A valid citation proves quoted text, not the correctness of every surrounding assertion.

## One candidate, not an endless prompt loop

The candidate applied the evidence boundary to internal materials and decision reviews and explicitly limited claims derived from sparse excerpts. Its first A request yielded no result after the local 110-second timeout; retries hit the local forwarding cap. B completed. One separately recorded, bounded transport retry of A used the same prompt/input/objective and a longer timeout; it completed. The timeout is retained and is not evidence of provider quota exhaustion or zero billable work.

The repeated model still:

- proposed a normative document/payment checklist without supporting documents or an applicable jurisdiction;
- strengthened the synthetic author's “not paying yet” into a no-upfront-payment requirement;
- called C07 inactive despite only a sparse selected card;
- described one C09 roundup as regular publication.

The independent review reached a partial semantic result with residual failures. The candidate was rejected and the exact canonical prompt restored. There was no additional prompt/rerun. This agrees with the prior `AUDIENCE_INTERPRETATION_FIDELITY_V1.md` finding: instruction changes alone had not established general faithful interpretation. Different stochastic output on twelve known cases cannot prove causal improvement or general model accuracy.

Exact cards, separate gold, original outputs including the failed attempt, two prompt snapshots, independent review and hash manifest are in [the regression dataset](../benchmarks/audience-internal-evidence-boundary-v1/README.md).

## Durable state and recovery

Eleven executable assertions ran on disposable clones of the actually accepted baseline A Store, with the synthetic C12 need owner-accepted only inside each clone:

- A necessary source edit/delete immediately made the need non-current; `audience.open_work` rejected with `AUDIENCE_STALE_BASIS`. Reconciliation made it stale, and restart preserved that state.
- Editing C01, which the actual C12 context review classified unrelated, temporarily produced scope backlog and recovered the accepted/current C12 after reconciliation. It did not permanently poison the need.
- Removing source authority made the source unusable. Reconciliation revoked the watch and staled the need; restoring the allowlist and restarting did not revive either terminal record.

The original Store hash was unchanged. This tests native Audience evidence/authority lifecycle, not a typed advertising-route revocation feature. All checked side-effect records were empty. Existing source/freshness/review boundaries were retained.

## Validation and practical limits

Both the prompt-only candidate and the final state with the canonical prompt restored passed **1,784 Node tests + 41 Python credential-isolation tests + build + `git diff --check`**. The candidate's software pass did not override its semantic failure. The final dataset JSON and all eleven manifest-pinned files were also verified against staged Git bytes. Hosted exact-head CI is a separate check.

Five requests were forwarded to CLIProxy; four completed. Completed worker receipts total **37,986 input / 8,339 output tokens**. The remaining request's billable usage, hidden upstream retries/account rotation, monetary cost, account percentage and independent upstream model identity remain unknown. No money figure is inferred from receipt zeros or the requested alias.

There were no prospect sends, person/conversation/draft/send authority grants, or enduring production activations. Public research remains read-only. A draft is not a send, an association is not causal credit, and an unknown outcome is not success.

## Product decision with the dev

Use the current system as a review-assisted research radar. It has not demonstrated autonomous qualification or reliable legal/financial advice. The two most relevant researched publisher sources are still research candidates; no interest or recipient permission was established.

The code audit found Scout's campaign/sample-bound assessment machinery, not an implemented generic SourceMap or typed professional-publisher/ad-route assessment. Do not disguise campaign audience fit as publisher identity/role, or add a second fact registry merely to store these two sources.

The next material prerequisite for a YOVI financial pilot is establishing current operator/product/terms and the actual offer. Existing owner-provided presentations and transcripts establish what was stated in those versions; they do not establish current complete conditions. Public source research may continue independently, but more contacts or another assessment layer cannot establish those missing facts. The prepared document request remains unsent. Only after the offer is grounded should a voluntary, separately authorized pilot or a genuinely different configured reasoning profile be evaluated. No contact authority is inferred from these tests.
