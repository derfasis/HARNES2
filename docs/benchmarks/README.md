# Benchmark Reports

Raw benchmark reports remain ignored and local. They may contain full prompts, context, tool schemas, messages, and other sensitive material; do not force-add them with `git add -f`.

GitHub receives only an allowlisted summary after a secret and personal-data scan. A summary may include run metadata, aggregate metrics, synthetic inbound/draft pairs, action labels, safety flags, review findings, and the scan result. It must not include API keys, key fingerprints, base URLs, full prompts, system identity, skills, tool schemas, raw result objects, local absolute paths, or real contact data.
